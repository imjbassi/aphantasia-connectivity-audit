Data and code accompanying the manuscript "Reduced frontoparietal-visual connectivity in aphantasia: an audit of the imaging evidence and its citation record".

Contents:
- data/extraction_studies.csv: 19 studies, sampling and group definition, with a verification-depth tag per row (full text, preprint, abstract only, not retrieved)
- data/extraction_connectivity.csv: every connectivity analysis, by state and seed
- data/citation_coding.csv: coded citing sentences for the sources whose passages were retrieved
- osf/registration_draft.md: pre-registration plan for the resting-state reanalysis
- scripts/: power figures, reference resolution, corpus download and value checking
